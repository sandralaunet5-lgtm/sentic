# GRNB ADVISORY — Site Web Officiel

Bienvenue sur le dépôt GitHub officiel du site web de **GRNB ADVISORY**, cabinet d'analyse macroéconomique et de recherche quantitative.

## 📌 Présentation du Projet
Ce site web vitrine institutionnel est conçu avec un style moderne, froid et épuré, adoptant une charte graphique orientée finance de marché (tons bleu nuit, bleu acier, bleu glacier et arrière-plans d'architectures financières).

## 🗂️ Structure des Fichiers
- `index.html` : Structure HTML5 du site (Hero, Tickers, Solutions, Services, Recherche, Contact, Footer, Modale).
- `style.css` : Feuillets de styles CSS3 personnalisés (design responsive, palette de couleurs, typographies).
- `script.js` : Fonctions JavaScript pour la gestion des modales vidéo, ouvertures de services et formulaires.
- `README.md` : Documentation du dépôt.

## 🚀 Déploiement sur GitHub Pages
1. Importez tous ces fichiers à la racine de votre dépôt GitHub.
2. Rendez-vous dans les paramètres du dépôt (**Settings** > **Pages**).
3. Sous la section **Build and deployment**, sélectionnez la branche `main` (ou `master`) et le dossier `/ (root)`.
4. Enregistrez : votre site sera publié en ligne automatiquement.
